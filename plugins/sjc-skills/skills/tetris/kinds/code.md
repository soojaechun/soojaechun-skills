# 코드

폴더·모듈 안의 파일 배치를 볼 때 읽는다. 쓰는 사람은 이 코드를 읽고 고치는 개발자다.

## 조각과 칸 찾기
- 조각: 파일 (큰 파일이면 그 안에서 내보내는 함수·클래스)
- 칸: 폴더, 패키지, 모듈
- 프로젝트 문서(README, CLAUDE.md, CONTRIBUTING)에 정한 폴더 규칙이 있으면 기준에 넣는다.

## 엮임 세기
- import: 이 파일이 불러오는 파일과 이 파일을 불러오는 파일을 칸별로 센다 (Grep으로 import·require·from 문을 찾는다)
- 이름: 같은 도메인 단어를 쓰는 파일끼리

## 이 종류에서 더 볼 신호
- 한 폴더 안 파일들이 서로는 거의 부르지 않고 주로 다른 폴더와 엮인다
- 같은 일을 하는 도우미 함수가 여러 폴더에 있다
- 두 폴더가 서로를 부른다 (순환)
- 어디서도 불리지 않는 파일
