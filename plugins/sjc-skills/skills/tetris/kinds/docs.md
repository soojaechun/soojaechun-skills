# 문서

문서 묶음(폴더)이나 문서 한 편의 목차를 볼 때 읽는다. 쓰는 사람은 그 문서를 읽는 사람이다.

## 조각과 칸 찾기
- 문서 묶음: 조각은 문서, 칸은 폴더나 색인(README, 목차 문서)
- 문서 한 편: 조각은 절(제목 아래 한 덩어리), 칸은 장
- 문서 첫머리의 상태 표시(초안, 옛 사본, 폐기, 확정)와 문서 사이 우선순위 규칙을 먼저 읽는다.

## 엮임 세기
- 링크: 문서끼리 서로 건 링크와 파일 경로 언급
- 주제: 같은 용어·같은 기능을 다루는 문서·절끼리
- 순서: 읽는 사람이 차례로 따라가는 절차의 앞뒤

## 이 종류에서 더 볼 신호
- "옛 사본", "따르지 않는다", "폐기" 같은 표시가 붙은 문서 (고아)
- 같은 규칙이 두 문서에 적혀 있다 (겹침)
- 한 주제가 여러 문서·장에 흩어져 있다
- 어떤 색인에서도 링크되지 않은 문서
