# 내비·화면

웹·앱의 메뉴 구조(탭, 하위 탭, 사이드바)나 화면 하나의 섹션 배치를 볼 때 읽는다.

## 조각과 칸 찾기
- 메뉴 설정: 사이드바·탭·헤더 메뉴를 정의한 파일을 찾는다. 이름에 nav, menu, sidebar, routes, sitemap이 들어간 파일이 흔하다.
- 라우트: 프레임워크의 라우트 정의를 찾는다.
  - Next.js App Router: `app/**/page.*` (괄호 폴더 `(group)`은 주소에 들어가지 않는다)
  - Next.js Pages Router·Nuxt: `pages/**`
  - SvelteKit: `src/routes/**/+page.*`
  - React Router·Vue Router·Angular: 라우트 배열을 정의한 파일 (`createBrowserRouter`, `routes`, `RouterModule`)
- 메뉴 설정과 라우트를 맞대어 메뉴에 없는 페이지와 페이지가 없는 메뉴를 표시한다.
- 화면 하나가 대상이면 조각은 섹션·카드, 칸은 화면의 영역과 순서다. 그 화면 파일과 그 파일이 불러오는 컴포넌트를 읽는다.

## 엮임 세기
- 링크: 이 페이지에서 다른 페이지로 가는 링크·버튼 (`href`, `Link`, `router.push` 등)
- 같은 데이터: 같은 데이터 함수·API·테이블을 쓰는 페이지끼리
- 일의 흐름: 문서(기획, 화면 안내)에 적힌 작업 순서에서 앞뒤로 이어지는 페이지끼리

## 이 종류에서 더 볼 신호
- 메뉴가 3단 이상으로 깊다
- 메뉴 이름이 기능 ID·기술 용어·팀 이름이다
- 하위 메뉴가 하나뿐인 그룹, 일곱 개를 넘는 그룹
