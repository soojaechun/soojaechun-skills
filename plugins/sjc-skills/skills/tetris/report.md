# 보고서 틀

이 틀대로 대화에 보고서를 쓴다. `< >`는 채울 자리다.

```
## Tetris 보고서: <대상>

**쓰는 사람과 일**
- 쓰는 사람: <누구, 상황> (<출처>)
- 일: 1) <일> 2) <일> … (<출처 또는 "추정">)

**한눈에**: 조각 <N>개 · 유지 <N> · 이동 <N> (정리 <N> · 정렬 <N> · 재배치 <N>)

### 현재 지도
<칸과 조각의 나무 구조. 메뉴·폴더에 없는 조각은 "(고아)"로 표시>

### 제안 지도
<이동을 모두 반영한 나무 구조. 새 칸은 "(새 칸)"으로 표시>

### 이동 목록
우선순위가 높은 것부터.

**M1 · <동작> · <조각>**
- 어디서 → 어디로: <지금 칸> → <제안 칸>
- 쓰는 사람의 이득: <어떤 일이 어떻게 쉬워지는지>
- 근거: <칸별 엮임 수> (<파일:줄>)
- 고칠 때 바뀌는 것: 파일 <목록> / 따라 고칠 링크·import·주소 <목록> / 영향받는 담당자 <목록 또는 "문서에 없음">
- 우선순위: <높음·보통·낮음> (이득과 고칠 양을 견줘서)

### 유지
<조각 이름을 쉼표로>

### 확인이 필요한 것
<추정으로 판정한 것, 사람이 정해야 할 것>
```
